# Tài liệu gốc của môn học

Các file trong thư mục này là **tài liệu do giáo viên cung cấp** cùng mã nguồn mẫu ban đầu, được giữ nguyên để tham khảo:

| File | Nội dung |
|---|---|
| `0. NEW_COMPUTER_SETUP.md` | Hướng dẫn cài đặt môi trường gốc |
| `1. README.md` | README gốc của mã nguồn mẫu |
| `2. HANDS_ON_LAB_GUIDE.md` | Bài lab dbt + Airflow |
| `3. DATAOPS_LAB_GUIDE.md` | Bài lab DataOps (CI/CD, kiểm thử, giám sát) |
| `4. DATAOPS_PROJECT_REQUIREMENTS.md` | **Đề bài đồ án** và thang điểm |
| `docker_commands.md` | Các lệnh Docker thường dùng |
| `TROUBLESHOOTING.md` | Xử lý sự cố của mã nguồn mẫu |

Tài liệu của dự án (đã cập nhật theo hệ thống hiện tại) nằm ở thư mục [`docs/`](../) và [`README.md`](../../README.md) gốc.
